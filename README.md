# PyPhy Engine V1
PyPhy Engine is physics simulation engine mad with Pygame. It currently supports gravity, circular rigid bodies, and wall collision in V1,
it's quite buggy tbh (I'll be fixing that in future versions). In future versions, I will be implementing a draw function that lets you draw
a wall with your mouse. The code for this project is written by me and not copied from anyone, however ai was ocasionally used for debugging
when i couldn't seem to fix the error after thinking about it for a long time and i'm not that great at physics so
some physics concepts that i was not familiar with was either searched on google or learned from youtube video(not the implementation of code, just the physical concept) and that's pretty much it.

# How to run it
Make sure you have Python installed on your system, firstly you have to clone this repository
with ```git clone https://github.com/Manas-909/PyPhyEngineV1``` and then navigate to the project directory
with ```cd PyPhyEngineV1```, install the dependencies with ```pip install pygame``` and finally run the engine with ```python physics.py```
